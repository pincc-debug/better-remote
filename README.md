# Better Remote

让手机和平板远程操作 Mac 更顺手的 macOS 小工具，免费使用。配合 UU 远程、ToDesk 等远程软件使用。

- 一屏适配手机：内置手机、折叠屏、平板设备模板，按清晰度换算分辨率，字不再小
- 连上远程自动切换分辨率，断开自动还原（可关闭）
- 悬浮工具条：复制、粘贴、最小化、全屏、Enter、程序坞等常用操作一点就到，支持自定义快捷键
- UU 远程单指滚动（可选）：单指滑动滚动，按住 0.4 秒再拖为拖动

## 下载

前往 [Releases](../../releases/latest) 下载最新的 `.dmg`，打开后把 Better Remote 拖进“应用程序”。

## 第一次打开提示“无法验证开发者”？

本应用未经过苹果公证，第一次打开会被系统拦下：

1. 先双击打开一次，看到提示后点“完成”或“取消”。
2. 打开“系统设置 › 隐私与安全性”，在页面下方找到 Better Remote，点“仍要打开”，输入密码确认。
3. 如果提示“已损坏，无法打开”，在“终端”里执行下面这行后再打开：

   ```
   xattr -cr "/Applications/Better Remote.app"
   ```

首次使用时按提示授予“辅助功能”权限（用于快捷操作和单指滚动）。

## 系统要求

macOS（Apple 芯片或 Intel）。
