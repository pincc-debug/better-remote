## 解决什么问题

用手机远程电脑，最难受的是**屏幕对不上**：

- 电脑是 16:10 的大屏，手机是细长的竖屏或宽横屏，画面只能整体缩小
- 字小到看不清，四周留着大片黑边，点个按钮都要先双指放大
- 横屏凑合能看，竖屏基本没法用

Better Remote 的做法很直接：**把电脑的分辨率换成和手机一样的比例**。手机横屏、手机竖屏、平板、折叠屏都有现成的规格，也可以自己新增。画面刚好铺满手机，字是正常大小，不用缩放。用完一键还原，电脑回到原来的样子。

## 功能

### 📐 分辨率适配
- 内置手机横屏、手机竖屏、平板、折叠屏等规格，按清晰度换算，字不再小
- 支持新增自定义规格，适配你自己的设备
- 一点「还原本机」，立刻回到电脑原来的分辨率

### 🔗 连接自动化
- 远程连上，自动切换到你选好的分辨率
- 悬浮工具条自动展开，拿起手机就能用
- 断开连接，自动还原分辨率，坐回电脑前什么都不用调

### 🪟 窗口管理
- 贴在屏幕边上的工具条，内置多种布局：铺满、居中、左右平分、上下平分、左一右二、左二右一、上一下二、田字格、三列平分
- 先选布局，再按顺序点窗口，多个窗口依次排好，小屏幕上也看得清

### 👆 快捷操作
- 复制、粘贴、搜索、切换桌面、程序坞等常用操作，做成拇指大小的按钮
- 支持自定义组合键，并可为按钮挑选图标
- 不用在手机键盘上按一串组合键

### ⌨️ 应用专属快捷键
- 工具条的按钮随当前应用切换
- 比如在终端里一点左右分屏、上下分屏，换到别的应用就换成别的按钮

### 🖐 单指滚动
- 单指滑动就是滚动，按住约 0.4 秒再拖为拖动（可选）

### 🔄 自动更新
- 每 3 小时自动检查一次新版本，有更新会提示
- 也可以在菜单栏菜单里点「检查更新…」

## 安装

1. 双击打开 `.dmg`，把 Better Remote 拖进「应用程序」文件夹
2. 在「应用程序」里双击打开
3. 按提示授予「辅助功能」权限

## 更新

软件会自动检查并提示更新。

使用 **0.8.89 及更早版本**的用户，需要手动下载一次新版覆盖安装，之后就会自动更新。

## 常见问题

**为什么需要辅助功能权限？**
排列窗口、模拟快捷键和单指滚动都需要这个权限。软件只在本机执行这些操作。

**会不会把我的分辨率改乱？**
不会。断开远程时会自动还原，任何时候也可以点「还原本机」手动恢复。

**配合什么远程软件用？**
常用的远程控制软件都可以，Better Remote 只负责电脑这一端的适配。
