# Better Remote

让手机和平板远程操作 Mac 更顺手的 macOS 小工具，免费使用。配合常用的远程控制软件使用。

- 一屏适配手机：内置手机、折叠屏、平板设备模板，按清晰度换算分辨率，字不再小
- 连上远程自动切换分辨率，断开自动还原（可关闭）
- 悬浮工具条：复制、粘贴、最小化、全屏、Enter、程序坞等常用操作一点就到，支持自定义快捷键
- 单指滚动（可选）：单指滑动滚动，按住 0.4 秒再拖为拖动

## 安装

安装包已使用开发者证书签名并通过系统公证，下载后可以正常打开：

1. 双击打开 `.dmg`，把 Better Remote 拖进“应用程序”文件夹。
2. 在“应用程序”里双击打开即可。
3. 首次使用时按提示授予“辅助功能”权限（用于快捷操作和单指滚动）。

## 更新

从这个版本起，软件内置自动更新：有新版本时会自动提示，也可以在菜单栏菜单里点“检查更新…”，或在设置“常规”里点“立即检查”。

使用 0.8.89 及更早版本的用户，需要手动下载一次新版安装包覆盖安装，之后就会自动更新了。

## 系统要求

macOS 14 及以上。
